# PP Neue Montreal

The Figma file sets body text in PP Neue Montreal (Medium 500 and Bold 700), a font by
Pangram Pangram. Both files are in this folder and active (see `app/globals.css`):

- `PPNeueMontreal-Medium.woff2` for weight 500
- `PPNeueMontreal-Bold.woff2` for weight 700 (also used for semibold 600)

Check that your licence covers use on a website.
